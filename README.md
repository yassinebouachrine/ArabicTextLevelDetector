# Projet Arabic Text Complexity

Ce projet est disponible sur Docker Hub à l'adresse suivante : [bouachrineyassine/arabic-text-complexity](https://hub.docker.com/r/bouachrineyassine/arabic-text-complexity)

## Description

Arabic Text Complexity est un projet qui permet d'analyser la complexité des textes en langue arabe. Cette application web offre une interface utilisateur pour évaluer différents aspects de complexité textuelle en arabe.

## Prérequis

- Docker installé sur votre machine
- Connexion Internet pour télécharger l'image Docker

## Comment exécuter le projet

### Étape 1 : Télécharger l'image Docker

Exécutez la commande suivante pour télécharger l'image depuis Docker Hub :

```bash
docker pull bouachrineyassine/arabic-text-complexity:latest
```

### Étape 2 : Lancer le conteneur

Exécutez la commande suivante pour démarrer le conteneur en mappant le port 8080 de votre machine au port 8080 du conteneur :

```bash
docker run -p 8080:8080 bouachrineyassine/arabic-text-complexity:latest
```

### Étape 3 : Accéder à l'application

Ouvrez votre navigateur web et accédez à l'adresse suivante :

```
http://localhost:8080
```
